# AdScope — Marketing Performance Toolkit

AdScope is a lightweight, free, open-source campaign calculator built for media buyers and performance marketers.

## Current features (MVP)
- ROAS
- CPA
- CTR
- CPC
- CPM
- Conversion rate
- Break-even ROAS (based on product margin)
- Break-even CPA estimate (AOV × product margin)
- Live calculation and performance insight
- Responsive layout for desktop and mobile

## Run locally
No build tools or dependencies required. Open `index.html` in a modern browser.

## Important calculation notes
- Break-even ROAS uses `100 ÷ product margin (%)` and does not include overhead, fulfillment, payment fees, or taxes.
- Break-even CPA uses average order value × product margin. It is a simplified estimate before other costs.
- This tool is for directional analysis; validate numbers against your own attribution and accounting data.
